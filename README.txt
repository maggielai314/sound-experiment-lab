聲音實驗室 — 獨立 HTML 版

index.html 包含介面、原創樂器圖像及全部 39 個樂器錄音。
不需要 ChatGPT、GitHub、Node.js、安裝套件或外部聲音連線。

電腦：用 Chrome、Edge 或 Safari 開啟 index.html，按「啟用聲音」或樂器圖卡。
學生掃碼：須先將 index.html 放在 GitHub Pages／學校網站等一般 HTTPS 網頁空間，再把正式網址製作成 QR code。
手機／iPad：請透過正式網頁網址使用；聊天程式及檔案預覽可能不執行 HTML 內的程式。

沒有自動上載学生資料或雲端提交。聲音及顯示設定只保存在瀏覽器。
素材來源見 CREDITS.md。
