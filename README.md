- 對答案後：每格顯示 ✓／✗；每兩格之間顯示公式要求（全／半）同學生實際行咗咩；指出第一個出錯嘅位置及原因（例如「公式要全音 T，你由 E 去 F 係半音 S，應該係 F♯」）；顯示正確答案，鍵盤上綠線標示正確嘅鍵；可播放正確音階同自己砌嘅音階。
- 「↶ 刪一個」「重新砌」「下一題」；計分「答啱 x / y 題」（同一題重做唔重複計分）。
- 「全音・半音」頁加英文：半音 Semitone、全音 Tone、公式 T T S T T T S。
- 已測試：Chromium iPad 尺寸，D 大調錯答（F、C）及正確答案兩種情況；無程式錯誤。未在實體 iPad 測試。

## 上一版本 — 2026-10-16（力度及整體音量更新）

本次調整 **整體輸出訊號增益 +20%**，包括 pp–ff、樂器、伴奏、低音及拍子機；聆聽音量滑桿保留，零仍為靜音。在此基礎上，mf／f／ff 的倍率改為 0.64／1.28／2.56，兩個相鄰級距各約 +6 dB，讓高力度更易分辨。pp／p／mp 的相互比例保持不變。這是訊號增益與實際渲染結果，並不表示人耳感覺響度精確增加 20%。

保留修正 **Legato 音與音之間的連接**：每音維持至下一音開始，交接時最多 90 毫秒平滑交疊；小提琴、長笛及小號的後續音從持續發聲部分進入，避免每音重新起弓／起氣造成間隙。適用於單項「連奏與斷奏」及綜合實驗台。Staccato 的短音比例及空隙保持不變。

綜合實驗台保留三組直接可見的選項：

- **調式：大調／小調**。同一旋律的小調版本將第 3、6、7 級降半音；伴奏同步由 C／G／F 轉為 Cm／Gm／Fm。節奏不變。
- **音區：高／中／低**。旋律升一個八度、原位或降一個八度；伴奏音區保持不變。小鼓屬無固定音高樂器，不作移調。
- **低音重複：開／關**。以低音鋼琴 C2／C♯2 半音交替，每半拍一音，速度跟隨整體 BPM。此層獨立開關，關掉旋律、伴奏、敲擊後仍可單獨聆聽。
- **聲部簡化**：旋律、伴奏、敲擊各只顯示開／關。音量滑桿收進預設摺起的「進階」，保留原有音量調整。
- **固定明亮模式**：移除深淺模式切換及設定。舊瀏覽器即使保存了深色偏好，也會顯示明亮模式。

保留旋律長度、六種樂器圖卡、pp–ff、速度、Legato／Staccato、聲部控制、單項探索、目錄及自動保存。播放／停止維持在頂部，設定按底部功能掣展開。沒有匯出或學生登入。

### 課堂試玩

先用大調、中音區、低音重複關作比較，再試 **小調＋低音區＋低音重複開＋60 BPM**。建議以鋼琴或小提琴及 mf 開始。若探索悲傷感，可關掉低音重複，保留慢速小調與 Legato。情緒感受仍由學生實際聆聽、比較和描述。

### 已測試

- 49 項力度／音量檢查通過：六種樂器 pp／p／mp 相對舊版實際 RMS 增加 20%；mf→f、f→ff 單音約 +6 dB；所有六級依次增強。各樂器高低音區、全聲部及低音重複、最高聆聽音量混音仍保留力度差距、無削波；音量零可靜音。

- 46 項連奏音訊檢查通過：五種有固定音高的樂器 × 40／80／200 BPM，接位附近每 10 毫秒波形視窗均有聲音；前後音交接成對；同速 Staccato 在下一音前仍保留靜音空隙；停止即清除延音及未來排程。此檢查為客觀音訊渲染，並非人耳評聽。

- 21 項模型測試通過：連奏在每個音及跨小節接位到達下一音起點；其餘包括自然小調音高與伴奏、旋律八度轉移、低音半音交替及隨速度排程、舊版本資料升級、非法設定拒絕、單項頁原行為。
- 19 項新增實際採樣渲染測試通過：原版本與小調／低音／低音重複／60 BPM 組合產生不同波形；低音層確實輸出；各樂器高低音區在快速 ff 混合時無無效樣本或削波；全部關閉及停止後無殘留聲音。
- 23 項原有音訊回歸測試通過：39 個錄音全部解碼、六種樂器、力度、長笛長音、拍子機重拍、聲源停止及排程。
- 瀏覽器實際操作小調、低音區、低音重複、60 BPM、播放／停止、聲部開關和進階音量；重新載入後設定保留。
- 768×1024、1024×768、390×844 瀏覽器內框：播放／停止及七個功能掣一屏可見，無頁面水平／垂直溢出；展開進階仍不遮播放掣。
- 明亮背景、淺色原生控制，以及頁頂和設定內均無深色模式選項。

### 未能測試／限制

- 未在實體 iPad Safari、學校網絡、課室喇叭或多指觸控環境測試；內框尺寸不等同 iPad 實機。
- 音訊測試是 Web Audio 真實採樣的客觀渲染及波形檢查，並非人耳試聽；未能確認課室內「明顯更緊張」的主觀聽感。上課前請用實際裝置短播上述組合。
- 首次播放須由學生按「啟用聲音」或「播放」啟動聲音；切回背景後可再次按播放。實際音量亦受裝置靜音、系統音量及喇叭低頻表現影響。

## 本機開啟與維護

開發資料夾執行 `npm start`（需 Node.js），開啟 http://127.0.0.1:4173/ 。不用安裝 npm 套件。

- `dist/`：介面、模型、聲音引擎及本機採樣。
- `npm test`：模型測試。
- `/qa-audio.html`、`/qa-mood.html`、`/qa-legato.html`、`/qa-dynamics.html`、`/qa-layout.html`：本機專用檢查頁，不放進學生公開版。
- `node scripts/build-standalone.mjs`：產生 `student-html/index.html`，內嵌介面、圖像及 39 個錄音，毋須外部 JS、CSS 或音訊服務。
- 將 `student-html/index.html` 及更新的 README 上載至 **maggielai314/sound-experiment-lab** 的 `main` 根目錄；保留 `.nojekyll`。GitHub Pages 從 `main` 根目錄部署。發布後核對工作流程及匿名公開 HTML。
- `website/` 為舊 Sites 版本，現行公開版使用上述 GitHub Pages。
